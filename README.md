# Brisbane Bowser Beater

A web app for Brisbane drivers, combining live fuel price data with an AI-powered fuel strategist. Helps consumers time and locate their fills around recurring retail fuel price cycles in Australian capital cities.

Currently early-stage. The full README — product overview, cycle explanation, cost architecture, how to use, roadmap, contributing — is produced in Phase 7 of the build plan.
